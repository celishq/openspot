Closes the front tab of your browser and opens it again in that browser at the time you pick: Later, Tomorrow, Next Week or any date. It reads Safari, Chrome, Arc, Brave, Edge, Vivaldi and Opera, and says so when the front app is not one of them.

Press Return on Snooze Tab, or type snooze in the main search: the first row, Snooze Current Tab, names the tab it will snooze. Under it, Snooze Tab lists each snoozed tab with the time it comes back: Return opens one now, Copy Link in its ⌘K menu copies its link, ⌘⌫ removes it, and Open All opens every one. Give its Snooze Tab command a key to snooze from the browser itself.

Someday closes the tab and keeps it in the list with no time to come back. Openspot keeps each snoozed tab across a restart, and opens it when the Mac wakes if its time passed while it slept. Snooze Tab reads the front tab when its sheet opens or its rows first show in the main search, only while a browser is in front, and the press reads it again, so it never acts on an old tab. The first read asks for the Automation permission to control the browser. Openspot fetches the favicon of each snoozed page once from its site, with no cookies.
