Closes the front Safari tab and opens it again at the time you pick: Later, Tomorrow, Next Week or any date. Give Snooze Tab a key in its Settings, press it on a tab, and pick a tile.

Press Return on Snooze Tab, or type snooze in the main search, and pick Snooze Current Tab. Under it, Snooze Tab lists each snoozed tab with the time it comes back: Return opens one now, ⌘⌫ removes it, and Open All opens every one. Someday closes the tab with no time to come back. Openspot keeps each snoozed tab across a restart, and opens it when the Mac wakes if its time passed while it slept. The first press asks for the Automation permission to control Safari. Openspot fetches the favicon of each snoozed page once from its site, with no cookies.
