Closes the front Safari tab and opens it again at the time you pick: Later, Tomorrow, Next Week or any date. Give Snooze Tab a key in its Settings, press it on a tab, and pick a tile.

Open Snooze Tab to see each snoozed tab with the time it comes back. Return opens a tab now, and ⌘⌫ removes it. Someday closes the tab with no time to come back. Openspot keeps each snoozed tab across a restart, and opens it when the Mac wakes if its time passed while it slept. The first press asks for the Automation permission to control Safari. It sends nothing over the network.
